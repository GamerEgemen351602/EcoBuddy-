# 🌱 EcoBuddy

## 🌍 Proje Hakkında

**EcoBuddy**, insanların günlük alışkanlıklarının çevreye ve iklim değişikliğine olan etkisini fark etmelerine yardımcı olan basit bir **karbon ayak izi hesaplama uygulamasıdır**.

Kullanıcı günlük olarak yaptığı bazı aktiviteleri girer. EcoBuddy, bu bilgileri kullanarak yaklaşık karbon salımını hesaplar ve daha çevreci bir yaşam için öneriler sunar.

## 🎯 Projenin Amacı

Projemizin amacı, insanların karbon ayak izlerini kolayca fark etmelerini ve günlük hayatlarında yapabilecekleri küçük değişikliklerle **iklim değişikliğiyle mücadele etmelerini** sağlamaktır.

> 🌱 Küçük değişiklikler, büyük farklar yaratabilir!

## 💡 Nasıl Çalışır?

EcoBuddy kullanıcıdan şu bilgileri alır:

* 🚗 Arabayla gidilen mesafe
* 💡 Günlük elektrik kullanımı
* 🥩 Tüketilen et porsiyonu
* 🧴 Kullanılan plastik ürün sayısı

Daha sonra bu değerlerden yaklaşık bir karbon salımı hesaplanır ve kullanıcıya bir sonuç gösterilir.

Örneğin:

```text
🌍 Toplam: 7.45 kg CO₂

🌱 EcoBuddy'nin önerisi:
Kısa mesafelerde yürümeyi veya bisikleti deneyebilirsin!
```

## 🧮 Kullanılan Teknolojiler

* 🐍 Python

* 📝 GitHub / GitHub Repository

Bu proje temel Python özellikleri kullanılarak geliştirilmiştir ve çalıştırmak için ekstra bir kütüphane gerektirmez.

## 🚀 Projeyi Çalıştırma

Projeyi bilgisayarına indirdikten sonra terminalde proje klasörüne girip:

```bash
python ecobuddy.py
```

komutunu çalıştırabilirsin.

## 🌎 İklim Değişikliğine Katkısı

EcoBuddy, insanların günlük davranışlarının çevre üzerindeki etkisini görmesini sağlayarak daha sürdürülebilir seçimler yapmalarını teşvik eder.

Uygulamanın amacı insanları suçlamak değil, **bilgilendirmek ve küçük adımlarla daha çevreci davranışlara yönlendirmektir.**
